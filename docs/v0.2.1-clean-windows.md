# Clean Windows acceptance — pending manual qualification

Do not mark this gate passed based on a developer workstation or Windows Server
CI. Use a fresh Windows 11 x64 VM or supported clean physical machine, a standard
user account and no developer tools. Windows Sandbox is not available on the
current build host. Do not install/enable virtualisation or weaken OS protections
just to claim this gate.

1. Obtain the candidate ZIP through the intended download path. Record its SHA-256,
   Windows build, machine architecture and any SmartScreen/publisher warning.
2. Disconnect the guest network. In File Explorer choose **Extract All**, then
   double-click `DAF.exe` in the extracted folder. No terminal or runtime install.
   If security policy blocks the unsigned candidate, stop: signing is still a gate.
3. Complete onboarding for both assistant choices. Try all three permission modes.
   In independent mode approve the plan, then review and finish each milestone.
4. Try setup failures and their named fixes, every boundary exception, Stop during
   work and a review, Ctrl+R interruption and Check earlier work recovery.
5. Use only the keyboard for a complete suggestions journey, zoom to 200%, and
   check Narrator announcements, focus, radio choices and Stop visibility.
6. Close with X while a simulation is active. Confirm no DAF process remains and
   reopen to a fresh welcome screen. Record the lost-progress explanation.
7. Close, delete the extracted folder/ZIP and optionally `%APPDATA%\DAF Offline Demo`.
   Confirm there is no service or startup entry and no developer-tool dependency.

Record each outcome, screenshot and blocker in the PR. This checklist is an
acceptance procedure, not evidence that it has been performed. Code signing and a
real downloaded-file reputation check are required before non-technical public
distribution. A hash identifies a candidate; it is not a signature or trust bypass.
