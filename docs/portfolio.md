# Presentation kit

Suggested repository name: **development-autonomy-framework**.

Suggested description: **An offline developer preview of durable AI development
orchestration: explicit plans, retained evidence, recovery and bounded execution experiments.**

Five demonstrated capabilities:

1. Validate explicit milestone dependencies, scope and acceptance criteria.
2. Keep failed attempts and correction evidence in a durable execution journal.
3. Reconcile synthetic work across restarts without duplicate fixture dispatch.
4. Stop new admission and experiment with atomic budgets and bounded checkpoints.
5. Inspect synthetic progress in a static, read-only Mission Control dashboard.

DAF grew from challenges encountered while building **Victoria**: making plans
explicit, preserving failed attempts, recovering safely and knowing when to stop.
This standalone preview demonstrates those ideas with synthetic data. Victoria's
pinned controller has not adopted this preview. No Victoria source or execution
history is included.

## Article outline: automation needs more than code-writing agents

- Start with the practical question: how does an owner know what an agent is
  allowed to do, what it has done and when it should stop?
- Explain why a plan, an execution attempt and independent acceptance evidence
  must be distinct records. A developer's success claim is not acceptance.
- Show the synthetic failed attempt beside its successful correction. Keep both.
- Explain restart ambiguity: a lost response is not proof that work never happened.
- Show the bounded fixture refusing another segment. Be explicit that real
  provider spending guarantees remain unproven.
- Show Mission Control's separate development, merge and deployment states.
- Close with the developer-preview invitation: inspect and test the control
  contracts; help establish evidence for safe live transports before activation.

Suggested recording: 45–60 seconds using the offline walkthrough. Keep its
synthetic label visible. Do not claim unrestricted autonomy, production safety,
provider-certified caps or a live owner-approval service.
